00 / Context

先理解，再生成

DID 不是用户名，也不是某个平台里的账号。它把“我是谁”的证明放回密钥持有者手中。A DID is not a platform account; control comes from the key holder.

01

什么是 DID？

去中心化标识符（Decentralized Identifier）是一种可验证、可移植的身份字符串。别人无需询问中心化账号系统，就能用它对应的公钥验证你的签名。

A DID is a portable identifier whose public key lets anyone verify your signatures.
02

为什么选择 did:key？

did:key 直接把带类型信息的公钥编码进 DID：无需链上交易、注册中心或网络查询。一个字符串就足以开始验证。

did:key embeds the typed public key itself—no registry, blockchain transaction, or network lookup.
03

Technocore 如何使用它？

Technocore 让消息与 Ed25519 身份绑定。发送者签名，任何人都能用 DID 中的公钥核验消息确实来自同一身份。

Technocore binds messages to an Ed25519 identity through verifiable signatures. Built by @flop_labs.

02MULTICODEC

添加 multicodec 前缀 / Prepend multicodec

0xED 0x01 · 34 bytes

ed01 表示“后面的数据是 ed25519-pub”；前缀与 32 字节公钥合并为 34 字节。The bytes ed 01 identify the payload as an ed25519-pub key, producing 34 bytes total.

ed01 + [32-byte public key]
03BASE58BTC

编码为 base58btc / Encode as base58btc

Bitcoin alphabet

用 Bitcoin base58 字母表编码 34 字节，避开容易混淆的 0、O、I、l；前导零字节会保留为字符 “1”。Bitcoin base58 avoids ambiguous characters and preserves each leading zero byte as “1”.

等待 34 字节输入… / Waiting for 34-byte input…
04FINAL DID

加上 multibase 与方法名 / Add multibase & method

did:key:z6Mk…

字符 z 声明后面使用 base58btc；再加上 did:key:，得到最终身份。“z” declares base58btc; “did:key:” turns the encoded key into the final identifier.

did:key: + z + base58btc(ed01 + raw_public_key_32bytes)
